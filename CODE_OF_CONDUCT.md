# Code of Conduct

## Our commitment

SkillMirror AI aims to be a welcoming, constructive, and respectful project for contributors of different backgrounds, abilities, experience levels, and perspectives.

## Expected behavior

- Be respectful and considerate.
- Give and accept constructive feedback gracefully.
- Focus on what is best for learners, instructors, and the project.
- Ask questions instead of making assumptions about another contributor's intent.
- Respect privacy, consent, intellectual property, and accessibility needs.
- Help keep discussions inclusive, professional, and on topic.

## Unacceptable behavior

- Harassment, discrimination, personal attacks, or intimidation.
- Sexualized language or unwelcome attention.
- Publishing private information without explicit permission.
- Trolling, sustained disruption, or bad-faith participation.
- Sharing training videos, faces, workplace information, or other sensitive material without the necessary permission.

## Scope

This code applies to project spaces, including issues, pull requests, discussions, project events, and public communication when someone is representing the project.

## Reporting

Report conduct concerns privately to the project maintainers using the contact method published in the repository or organization profile. Do not post sensitive evidence publicly. Include a description of the incident, relevant links, and any context you are comfortable sharing.

Maintainers should review reports promptly, fairly, and confidentially to the extent practical. They may edit or remove harmful content, issue a warning, temporarily restrict participation, or remove a contributor from the project for behavior they determine is unacceptable.

This is a project-specific code of conduct and does not replace applicable laws or platform policies.
