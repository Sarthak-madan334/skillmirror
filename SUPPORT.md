# Support

## Getting help

For questions about setup or how the prototype is intended to work:

1. Read the [README](README.md).
2. Review [Development](docs/DEVELOPMENT.md), [API design](docs/API.md), and [Testing](docs/TESTING.md).
3. Search existing issues before opening a new one.
4. If the question remains unanswered, open a discussion or issue with a concise description and the relevant environment details.

## Reporting a bug

Use the [bug report template](.github/ISSUE_TEMPLATE/bug_report.md). Include the steps to reproduce, expected and actual behavior, and relevant logs with secrets and personal information removed.

## Requesting a feature

Use the [feature request template](.github/ISSUE_TEMPLATE/feature_request.md). Explain who benefits, the problem, the proposed outcome, and how success could be tested.

## What not to share

Do not attach real learner videos, faces, private workplace recordings, API keys, medical information, passwords, or personal records to a public issue. Use synthetic examples where possible.

## Prototype limitations

SkillMirror AI is an experimental training aid, not an accredited qualification system or a substitute for a qualified instructor. AI-generated steps and automated visual checks can be wrong. Do not rely on the prototype to validate dangerous or safety-critical tasks.
